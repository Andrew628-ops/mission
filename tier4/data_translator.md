**problem**
Data translator

1. Prompt the user to enter their name.
2. Check if name is a valid string (contains only letters/characters and is not empty).
	- If valid, encode the string into binary and store it in memory.

	- Else, display "Invalid name. Please enter text" and return to Step 1.
3. Prompt the user to enter their age.
4. Check if age is a valid integer (int, a whole number).

	- If valid, convert the integer into binary and store it in memory.

	- Else, display "Invalid age. Please enter a whole number" and return to Step 3.
5. Prompt the user to enter their account_balance.
6. Check if account_balance is a valid floating-point number (float, a decimal number).

	- If valid, convert the float into binary and store it in memory.

	- Else, display "Invalid balance. Please enter a decimal number" and return to Step 5.
7. Prompt the user to enter whether the account is active (True or False), and check its data type.

	- If is_active is a valid boolean (bool), convert it into binary (1 for True, 0 for False) and store it in memory.

	- Else, display "Invalid status. Please enter True or False" and return to Step 7.
8. Display "All user data successfully stored" and end the program.

**The Problem:**
Withdraw money from an ATM

**Steps** 
1. Prompt the user to insert their ATM card.
2. Check if the card is valid.
3. If the card is not valid, display "Invalid card" eject the card, and stop the program.
4. If the card is valid prompt the user to enter their PIN.
5. Check if the entered PIN matches the user correct PIN.
6. If the PIN is incorrect, display "Incorrect PIN, please try again" and return to Step 4 (limit to 3 attempts before blocking the card).
7. If the PIN is correct, prompt the user to select "Withdrawal" and enter the requested amount.
8. Check the user available account balance.
9. If the available balance is less than the requested amount, display "Insufficient balance" and ask the user to enter a lower amount or cancel.
10. If the available balance is greater than or equal to (>=) the requested amount, dispense the requested cash.
11. Update the account balance using the formula new balance = available balance - requested amount.
12. Prompt the user to take their cash, eject the ATM card, and end the program.
